# Photographic scene assets

Original photographs downloaded from Wikimedia Commons on 2026-11-09.
See `sources.json` for individual authors, dates, source pages and licenses.

- `ponte.jpg`: Betty Lassini, 2021-09-04, CC BY-SA 4.0.
- `borgo.jpg`: tampe / Fabrizio Tampellini, 2007-10-28, CC BY-SA 3.0.

Files are source photographs or Wikimedia-resized versions, without AI generation or painted replacements.
At runtime the game crops/zooms them and overlays SVG facade areas and virtual
business signs. These adapted photographic scenes remain available under the
respective source CC BY-SA license. That does not change the license of unrelated
application source code. Attribution and license links are available in the scene.

No Google imagery or service is used. These are six flat photographs, not a 360°
panorama nor a current/live street recording. Facade-to-OSM bindings are approximate
game associations, not cadastral or verified commercial ownership. Protected
landmarks are not purchasable. Photographed people are not game characters.

Additional scenes: Piazza San Giorgio, Via Annoni / Via Cicogna, Via Fratelli Piazza, Via Matteotti (tampe / Fabrizio Tampellini, CC BY-SA 3.0). Exact source pages and dimensions are recorded in sources.json.
